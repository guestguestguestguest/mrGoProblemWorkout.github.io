Mr Go Problem Workout Support Page

MrGoProblemWorkout -- iOS app for practicing Go problems

MrGoProblemWorkout is for Go players wanting to improve their strength through repetitive problem solving. Import SGF files, one problem per file. You can import an entire directory (folder) or a ZIP archive of problem files. You can also create and run timed drills for further motivation.

Zipped problem file collections for importing (courtesy of benjaminmantle's baduk-study-material):

  • 299 Basic Tesuji
  • 390 Basic Tsumego
  • Gengen Gokyo
  • Gokyo Shumyo
  • Shikatsu Myoki

Additional SGF problem files are available from gogameguru sgfs on github

App Instructions:

To start, you need to import some problems. If you already have a collection or collections you want to study, that's great -- this app was made for you and me. If not, no worries, this app comes with a starter bundle of 24 problems (from the Chinese classic Xuanxuan Qijing), as well as five other prepared collections for importing. On the Problems tab click the '+' button on the top right to access the various import options. The top three 'Import...' perform as named. 'Load Starter Bundle' loads the 24 builtin problems mentioned above. 'Download Collections' lists five other collections available for downloading.
The Problems tab: All individual problems are listed on the Problems tab. You can filter the view via the two buttons on the upper left. Create and edit tags by swiping left on any problem. Mark a problem as a Favorite by swiping right.
The Collections tab: Once you import a collection of problems, it will be listed on the Collections tab. A tag of the collection name is automatically attached to all problems in that collection. You can rename, merge or delete collections by swiping left on the collection. Two collections are automatically created for you: 'Most Difficult' and 'Favorites'. The contents of these are dynamic and change based on usage.
The Drills tab: Here's where the fun is -- click the '+' button to create a drill from problems. Select your problems and give it a name. Once you create a drill it will appear in the Drills list. Tap to select a drill; the Run button will present each problem for solving with no hints allowed. Upon completion your time is saved in the run history, sorted by best (shortest) time. You can see an individual problem in the drill list without running the drill by long-pressing the desired problem. Exiting the problem will return you to the drill.
Settings: You can adjust drill size (minimum and maximum number of problems) in Settings. Other settings include board color, enabling/disabling sound, hints, random rotation and more.
How to prepare problems: This app uses standard SGF files, one problem per file. A simple, straightforward problem consists of a starting board position followed by proper moves to the problem completion. Problems with multiple paths require the final position for each path to have a comment indicating right (correct) or wrong (incorrect or fail).

I hope this app helps you enjoy studying a bit more! Send questions, comments or other feedback to mrmrsupport@protonmail.me
